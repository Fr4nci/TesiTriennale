# Elaborato di tesi triennale

Elaborato di tesi triennale sostenuta all'Università di Pisa, durante l'anno accademico 2025/2026. L'elaborato si basa sullo studio del potenziale gravitazione in presenza di deviazioni dalla simmetria sferica delle distribuzioni di masse: si è eseguita una simulazione numerica in cui, partendo dal dataset *EIGEN-6C4*, è stato ricostruito il potenziale gravitazionale della Terra, tramite l'implementazione dell'algoritmo riportato nel paper di Holmes e Featherstone per il calcolo delle armoniche ad alto $l$.
